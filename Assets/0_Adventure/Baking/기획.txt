핵심 개념
재료 : 가공 및 재료끼리 섞기와 가공 가능
혼합재료 : 2개의 재료를 섞은 것. 반죽, 시럽, 등등. 혼합재료도 재료와 같은 취급으로 섞기와 가공 가능. 혼합재료끼리도 섞기 가능
반죽 : 물과 밀가루가 섞인 재료. 반죽(구성1, 구성2)식으로 나와야 함

섞기 : 새로운 재료가 되거나, 구성요소만 추가될 수 있음
가공 : 재료가 변하거나 그렇지 않음

레시피 : 미리 정의한 반죽 구성 요소들
오븐 : 반죽을 넣어 완성품을 만듬. 정의된 레시피가 없다면 실패

판매 : 결과물은 각각 가치를 지니고 판매 가능

현재 가능한 변화
이스트가 있는 반죽 -> 발효
버터 -> 불 -> 헤이즐넛 버터
밀가루 + 물, 계란 등 액체류는 반죽

결과물 : ()안에는 가격
발효된 반죽 -> 오븐 -> 빵(40)
밀가루, 계란, 버터, 설탕 -> 오븐 -> 파운드 케이크(80)
헤이즐넛 버터, 계란, 설탕, 밀가루 -> 오븐 -> 휘낭시에(120)
