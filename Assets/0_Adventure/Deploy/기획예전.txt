===건물 뽑기 게임===
- 건물들의 위치는 자유롭게 바꿀 수 있음
- 뽑기 버튼을 눌러 재화를 소모해 건물을 뽑을 수 있음. 기업, 주거지, 편의 시설이 나옴
- 뽑거나 조합이 아니라 지을 수 있는 건물이 있음(학교, 공원, 하수처리 시설 등). 별도의 능력을 보유함
- 건물을 짓거나 강화하기 위해서는 재화필요
- 기업, 주거지의 수용가능 인원, 시간당 버는 돈, 입주율, 기타 건물들의 버프 효과, 건물 짓기 위한 재화 종류와 가격, Lv별 효과, 버프 효과 칸 범위, 건물 조합식 등 관련된 모든 기획 데이터는 SO등 외부 작업으로 설정 가능해야함


===기업===
데이터 : 기본 시간 수익, 총 일자리 수, 노동장 1명당 시간수익
- 현재 일하고 있는 사람들의 배로 지정된 골드를 범
- 스타트업 : 10명, 200
- 오피스텔 : 20명, 400
- 기업 빌딩 : 50명, 1000

===주거지===
데이터 : 기본 시간 수익, 거주 가능 인구, 기본 입주율, 취직 가능 범위
취직 가능 범위에 기업이 있다면 출근함
- 원룸 : 10명, 30% 양 옆 좌우 1칸
- 빌라 : 20명, 40%, 상하좌우 1칸 (대각선 X)
- 아파트 : 50명 50%, 대각선 포함 상하좌우 1칸

===편의 시설===
데이터 : 기본 시간 수익, 버프 범위, 증가 돈 효율
- 카페 : 양 옆 좌우 1칸
- 식당 : 상하좌우 1칸 (대각선 X)
- 복합 건물 : 대각선 포함 상하좌우 1칸


===공공 시설===
데이터 : 기본 시간 수익, 버프 범위, 증가 입주율
- 경찰서 : 위쪽 대각선 양옆 1칸 : 5%
- 소방서 : 대각선만 1칸 : 5%
- 도서관 : 상하좌우 1칸 : 10%


===퀘스트===
처음 뽑기, 처음 조합, 시청 2렙 달성처럼 1회 달성에 한해 보상을 주는 기능



===레벨 디자인===
- 시작은 3X3칸만 주어짐. (1,1)좌표에 시청 존재, 시작 골드 5000
- 모든 시설은 기본 시간 수익이 존재하며 10초당 획득함. 건물당 별개 사이클이 아니라 동일 사이클에 일괄 획득
- 뽑기 골드 500
- 조합은 레벨별로 2000G, 5000G가 듬
- 회관 렙업은 3000G, 10000G, 50000, 500000G가 듬
- 같은 카테고리의 건물 3개를 조합해 상위 레벨로 조합 가능
- 거주지, 일자리, 편의시설, 공공 시설 3LV까지 존재
- 모든 건물 기본 골드는 Lv당 100G, 300G, 1000G
- 시청은 3X3시작 -> 4X4 .....10X10형식으로 칸 증가


===UI/UX===
-맨 위에 현재 골드, 입주 주민/최대 수용가능 주민, 노동자/총 일자리 형식으로 표기되야 함
-조합 전용 UI가 있음. 조합 버튼을 누르면 조합 테이블이 팝업되고 건물마다 레시피와 버튼이 나오며 조합 가능 시 버튼이 활성화됨. 팝업 끌 수 있음
-회관 업그레이드 비용이 표기되야함
-조합에 비용이 들고 표기되어야 함
-건물을 클릭 시 건물의 정보(기본 골드 등 데이터)와 효과 범위가 표기되어야 함 

-드래그를 통해 건물 움직일 때
조합 불가능하면? -> 서로 위치 변경
비어있다면? -> 건물 이동
