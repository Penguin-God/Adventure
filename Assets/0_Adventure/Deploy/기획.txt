가로형으로 즐기는 2d 탑다운 픽셀아트 모바일 게임
한줄 요약 : 2차원 정사각형 칸에 건물과 타워를 배치해 돈을 벌고 몰려오는 적을 막는 게임
테마 : 배치와 연결

===공통 개념===
골드 : 소모, 추가, 관리
칸 : 건물이 존재할 수 있는 격자 공간
마을 : 10X10의 칸으로 이루어진 전체 공간. 각 칸마다 어느 건물이 배치됐는지 관리
건물 : 칸에 배치 가능하고 각 고유한 타입과 동작을 가지는 것
건물 타입 : 공장, 도로, 타워, 공장 속도 버프, 타워 공격력버프
타워 : 공격력, 공격속도, 사정거리, 저장가능 총알 수, 총알 타입을 가짐. 공장과 연결되어있는지를 상태로 가짐
공장 : 시간당 총알 생산수, 총알 타입, 범위를 가짐. 데이터에 따라 총알을 생성함
도로 : 공장과 타워를 연결함. 범위를 가짐. 공장과 타워 사이에 도로가 있다면 생성된 총알을 타워로 보냄


======로비(건축) 씬===
게임을 시작하면 들어오는 기본 씬
건물 배치 : 재화를 소모해 특정 칸에 선택한 건물을 배치
버튼을 통해 디펜스 스테이지 진입 가능. 스테이지별 데이터 존재


===디펜스 씬===
타워 : 사정거리 안에 있는 적을 향해 추적하는 투사체를 발사함. 공격시 총알 소모 없으면 대기
투사체 : 오직 지정한 적에게만 충돌 시 대미지를 입힘
몬스터 : HP를 가지며 마을을 둘러싸며 1바퀴를 돌며 이동함
목적지 : 몬스터의 최종 목적지는 출발한 곳에서 1바퀴를 돌아 다시 도착하는 것
패배 : 1마리의 몬스터라도 목적지에 도착하면 패배
승리 : 모든 몬스터를 잡으면 승리
디펜스 전용 골드 : 덱에서 타워를 소환하는데 사용
덱 : 건물 리스트를 담은 것. n장까지 제한있음

타워 소환 : 전체 덱 중 일부 n장만 소환 가능함. 소환한 카드는 덱에서 맨 뒤로 가고 다음 순서의 건물이 소환가능 형태로 변경되며 이게 반복됨
-소환 범위 : 랜덤한 위치에 소환됨. 또한 타입별로 소환가능 위치가 다름

도로 : 도로는 덱에서 제외된 채 언제든지 돈을 지불하고 설치 가능함. 도로는 상하좌우 중에 공장이나 다른 도로가 있는 공간에만 설치 가능. 
총알 수급 : 공장 혹은 연결된 도로의 상하좌우, 대각선 1칸 범위 안에 있는 타워에 총알을 제공함
도로로 연결되어있는 공장들에서 총 생성되는 총알이 타워로 더해짐
총알은 공장과 연결된 도로의 범위 안에 있는 타워 중 제일 적은 타워에 공급됨. 다 똑같다면 가까운 것부터.

첫 설치 시에는 총알이 전부 장전되어있음
총알이 0이 되면 풀충전될때까지 공격안함

-UI/UX-
건물 버튼을 클릭하면 설치모드로 바뀜. 일반 건물은 설치 시 바로 모드가 취소되지만, 도로는 설치해도 지속됨
건물 취소 버튼을 눌러 건축모드 취소 가능
건물에 따라 설치할 수 없는 칸은 연한 빨간색으로 표기
버프와, 도로 등 주변에 영향을 주는 건물들은 클릭 시 주위에 연한 초록색으로 범위 표기. 다른 아무 클릭이나 받으면 표기 멈춤
총알은 건물 위에 현재 총알/최대 총알 식으로 표기되어야함. 총알이 바닥나 공격불가 상태면 텍스트가 빨간색으로 변함


===기타===
- 건물들의 위치는 자유롭게 바꿀 수 있음
- 모든 기획 데이터는 SO등 외부 작업으로 설정 가능해야함
