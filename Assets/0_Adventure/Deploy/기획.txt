가로형으로 즐기는 2d 탑다운 픽셀아트 모바일 게임
한줄 요약 : 2차원 정사각형 칸에 건물과 타워를 배치해 돈을 벌고 몰려오는 적을 막는 게임
테마 : 배치

모드개념 : 모드(씬)에 따라서 다른 동작을 할 수 있고, 건물도 다르게 동작함

===공통 개념===
골드 : 소모, 추가, 관리
칸 : 건물이 존재할 수 있는 격자 공간
마을 : 10X10의 칸으로 이루어진 전체 공간. 각 칸마다 어느 건물이 배치됐는지 관리
건물 : 칸에 배치 가능하고 각 고유한 타입과 동작을 가지는 것
건물 타입 : 공장, 도로, 타워
타워 : 공격력, 공격속도, 사정거리, 저장가능 총알 수, 총알 타입을 가짐. 공장과 연결되어있는지를 상태로 가짐
공장 : 시간당 총알 생산수, 총알 타입, 범위를 가짐. 데이터에 따라 총알을 생성함
도로 : 공장과 타워를 연결함. 범위를 가짐. 공장과 타워 사이에 도로가 있다면 생성된 총알을 타워로 보냄
총알 수급 : 공장 혹은 연결된 도로의 범위 안에 있는 타워에 총알을 채움

===건축, 방치형 단계===
게임을 시작하면 들어오는 기본 씬
건물 배치 : 재화를 소모해 특정 칸에 선택한 건물을 배치
타워 : 수급된 총알의 가치에 따라 골드 추가


===디펜스 단계===
타워 : 사정거리 안에 있는 적을 향해 추적하는 투사체를 발사함. 공격시 총알 소모 없으면 대기
투사체 : 오직 지정한 적에게만 충돌 시 대미지를 입힘
몬스터 : HP를 가지며 마을을 둘러싸며 1바퀴를 돌며 이동함
목적지 : 몬스터의 최종 목적지는 출발한 곳에서 1바퀴를 돌아 다시 도착하는 것
패배 : 1마리의 몬스터라도 목적지에 도착하면 패배
승리 : 모든 몬스터를 잡으면 승리

===기타===
- 건물들의 위치는 자유롭게 바꿀 수 있음
- 모든 기획 데이터는 SO등 외부 작업으로 설정 가능해야함

===UI/UX===
-맨 위에 현재 골드, 수익률, 형식으로 표기되야 함
-건물을 클릭 시 건물의 정보(기본 골드 등 데이터)와 효과 범위가 표기되어야 함
