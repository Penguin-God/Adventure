가로형으로 즐기는 2d 탑다운 픽셀아트 모바일 게임
한줄 요약 : 2차원 정사각형 칸에 건물을 배치해 도로를 연결해 재료를 전달하고 제작해서 타워까지 보내서 적을 막는 게임
테마 : 배치와 연결

===기본 개념===
골드 : 소모, 추가, 관리
칸 : 건물이 존재할 수 있는 격자 공간
마을 : 타워 제외 건물 설치 가능 구역. 채굴장, 타워 구역 입구 등 미리 설치되어 움직일 수 없는 건물도 존재
타워 구역 : 타워, 타워 버프만 설치할 수 있는 구역. 입구가 마을에 배치되어 있고, 입구가 재료 수급 연결망과 붙으면 구역 전체에 재료 수급
건물 : 칸에 배치 가능하고 각 고유한 타입과 동작을 가지는 것
건물 타입 : 채굴장, 공장, 도로, 타워, 타워 버프
건물 이동 타입 : 자유, 고정
-자유는 이동, 판매 가능. 고정은 불가
타워 : 공격력, 공격속도, 사정거리, 저장가능 총알 수, 총알 타입을 가짐. 공장과 연결되어있는지를 상태로 가짐
공장 : 시간당 총알 생산수, 총알 타입, 범위를 가짐. 데이터에 따라 총알을 생성함
도로 : 공장과 타워를 연결함. 범위를 가짐. 공장과 타워 사이에 도로가 있다면 생성된 총알을 타워로 보냄


===로비 씬===
골드 : 건물을 짓는데 사용
건물 설치 : 설치는 로비에서만 가능하며, 지정된 칸에 설치 가능. 설치한 건물이 그대로 디펜스 씬에 적용됨.
-건축 모드 버튼을 누르면 모든 설치 가능 건물이 나오고 지을 수 없는건 비활성화. 지을 수 있는건 오른쪽 밑에 XN형식으로 얼마나 지을 수 있는지 표기
스테이지 : 진행 가능한 스테이지가 1~5까지 버튼으로 있음. 낮을 걸 깨야 다음으로 넘어갈 수 있음.
-스테이지당 몹 체력, 등장 수, 소환 딜레이, 클리어 획득 골드 등을 따로 설정할 수 있는 SO필요
-스테이지 진행에 따라 설치할 수 있는 건물의 종류와 숫자가 달라짐

===디펜스 씬===
타워 : 사정거리 안에 있는 적을 향해 추적하는 투사체를 발사함. 공격시 총알 소모 없으면 대기. 최초 생성시 총알은 0발
투사체 : 오직 지정한 적에게만 충돌 시 대미지를 입힘
몬스터 : HP를 가지며 목적지로 이동함
목적지 : 타워 구역 바로 아래에 직선으로 이동하며 그 끝이 목적지
실패 : 1마리의 몬스터라도 목적지에 도착하면 패배
성공 : 실패하지 않고 모든 몬스터를 잡으면 승리
채굴장 : 위치는 고정되어 있으며 개수는 하나. 기본 자원을 채굴하며 연결된 곳으로 수급. 초당 n개씩 생성
공장 : 필요한 재료들을 소모해 새로운 결과물을 만듬. 
도로 : 연결 범위를 늘리는 건물. 상하좌우 1칸씩 연결 가능.
재료 수급 : 본인 혹은 도로가 연결된 곳 중 자신의 재료를 필요로 하는 건물에 전달 가능.
-수급은 연결된 범위 안에 있는 건물 중 제일 적은 곳에 공급됨. 다 똑같다면 가까운 것부터.


===건물 간 연결===
-채굴장에서 획득한 재료는 근처 혹은 도로로 연결된 공장으로 이동
-공장에서 생성된 자원은 다른 공장이나 타워 구역 입구로 이동
-채굴장, 공장, 타워는 본인이 보유한 재료가 넘어갈때 제일 적은 건물부터 추가하고, 같다면 가까운 것부터
-결과 재료가 있는 건물은 셧다운이 존재함. 사용 재료 0이 되면 꽉 차야지만 사용 가능. 
-셧다운 시 채굴장은 채굴한 재료가 전달되지 않음(채굴은 함), 공장은 결과물이 전달되지 않음(제작은 함), 타워는 공격을 못함
-모든 연결된 공장들은 하나의 거대한 공장으로 취급함. 그래서 도로 없이도 전체를 연결 가능

===UI/UX===
-건물 버튼을 클릭하면 설치모드로 바뀜. 설치해도 지속됨. 건물 취소 버튼 클릭 or 빈 땅 클릭 시 취소
-건물에 따라 설치할 수 없는 칸은 연한 빨간색으로 표기, 설치 가능 칸은 연한 초록색
-빌드 모드 버튼을 누르면, 소환할 수 있는 건물들이 전부 버튼으로 표기됨. 이름(골드)형식으로 텍스트 표기

-버프와, 도로 등 주변에 영향을 주는 건물들은 클릭 시 주위에 연한 초록색으로 범위 표기. 다른 아무 클릭이나 받으면 표기 멈춤
-타워의 범위는 그냥 거리로 보여야 함
-재료는 건물 위에 현재 총알/최대 총알 식으로 표기되어야함. 재료가 바닥나 셧다운 상태면 텍스트가 빨간색으로 변함

-건물 위치 변경시 비어있는 곳에만 드래그로 이동 가능
-건물을 클릭하면 오른쪽 가운데에 판매 버튼이 나오고 누르면 원래 금액의 90%로 판매 가능. 판매 버튼은 평소에는 숨김 상태
-타워 구역은 입구에서 도로가 하나 더 튀어나와 있고 거기와 연결되어 있는 구역. 튀어나와있는 도로는 별도 기능 없는 시각적 구분선
-아웃풋 재료는 건물 위에 현재 양/최대 수용량으로 숫자표기, 공장에서 필요한 재료는 화면 아래에 재료1/재료 1최대, 재료2....순으로 표기

-화면 상단에 현재 골드 표기되어야 함
