클릭한 지형마다 확률에 따라 재료와 레시피가 나옴
레시피가 있으면 재료끼리 조합해 조합해 도구나 휘귀품 제작 가능
도구 : 판매 불가, 재료 해금 가능

지역 클릭 보상
숲 : 통나무, 수액, 꽃, 돌 곡괭이 레시피, 가공된 목재 레시피,
광산 : 돌, 철광석, 금광석, 원예 가위, 철 곡괭이 레시피, 특수 합금 레시피

---상점 목록 ---
-판매효율 증가
-나무 곡괭이 : 가공된 목재(5)
-철 곡괭이 : 나무 곡괭이 _ 철(10)
-원예 가위 : 철(5) + 통나무(30)
-공예품 레시피 : 꽃 + 금광석
-특수 합금 레시피 : 돌(10) + 철(3)
-가공된 목재 : 통나무(10) + 수액(3)

-재료 해금
기본 : 숲 통나무, 수액
나무 곡괭이 : 광산 돌, 철광석 해금
철 곡괭이 : 광산 금광석 해금
원예 가위 : 숲 꽃 해금
